🎵 My Playlist – C++ Project
A simple music playlist management system built using C++ and Singly Linked List.
This project allows users to manage their favorite songs through a menu-driven console application.
🚀 Features
Add Song: Add a new song to the end of the playlist.
Remove Song: Search for a song and remove it from the playlist.
Show Playlist: Display all songs with their numbers.
Count Songs: Display the total number of songs in the playlist.
Exit: Close the program.
🛠️ Technologies Used
C++
Struct
Classes & Objects
Pointers
Singly Linked List
Dynamic Memory Allocation (new and delete)
Constructor & Destructor
📋 Menu Options

💻 How to Run
Clone this repository:
git clone https://github.com/etman09/My-Playlist.cpp.git
Open the project folder.
Compile the source file:
g++ My-Playlist.cpp -o MyPlaylist
Run the program:
./MyPlaylist
